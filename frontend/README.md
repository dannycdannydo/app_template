# app-template frontend

Vue 3 + TypeScript + Vite application shell for the app-template starter.

- **State**: TanStack Vue Query (server) + Pinia (client)
- **UI**: Tailwind CSS + shadcn-vue (Reka UI primitives)
- **API**: typed client generated from the backend OpenAPI schema (`src/api/generated/`)

See `src/README.md` for the layout and command reference, and the
architecture blueprint §14–§16 for conventions.
